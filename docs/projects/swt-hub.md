# Resource Hub Site

![Project overview image](../assets/images/swt-hub.png)

## Overview

A public-facing ArcGIS Hub portal aimed at streamlining civic engagement and enhancing municipal transparency for local residents. The project involved configuring real-time spatial applications using tools like Survey123, StoryMaps, and ArcGIS Web AppBuilder to deliver live trackers for winter road plowing, leaf collection schedules, and active infrastructure projects. Additionally, I developed an integrated digital request system that allowed citizens to report, map, and monitor municipal issues directly, significantly reducing inbound support volume to the Public Works department. Throughout the development lifecycle, I managed underlying spatial datasets and layer integrations to ensure reliable access to vital public works and community development resources.

**Skill Highlight:** Full-stack website development

**Study Area:** South Whitehall Township  
**Role:** Solo project  
**Status:** Completed

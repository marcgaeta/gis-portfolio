# Walkability Analysis

![Project overview image](../assets/images/ped-shed.png)

## Overview

Created a website to serve as a GIS resource hub for a municipal government. Built out the site

**Skill Highlight:** Spatial analysis

**Study Area:** South Whitehall Township  
**Role:** Solo project  
**Status:** Completed

---

## Methods & Tools

**Data Sources**

- Aerial imagery tile map
- PennDOT road classification data
- Municipal boundary layer

**Processing Steps**

1. Imported data from various sources for basemap creation
2. Created a grid map to track project progress 
3. Moving grid-by-grid, digitized sidewalks from aerial imagery
4. Performed a pedshed analysis for a half-mile and 1-mile radius from schools in the Township

**Tools Used**

| Tool | Purpose |
|------|---------|
| ArcGIS Pro |  Map and layout creation |
| Spatial Analyst |  Pedhsed analysis |
